# zen-gateway

Бесплатный OpenAI-совместимый API для нейросетей. Один файл, ноль зависимостей.

## Что это, простыми словами

Есть сервис **opencode zen** — он раздаёт нейросети бесплатно (DeepSeek, Nemotron, Claude и другие) для продвижения своего продукта. Обычно к нему подключаются через их же программу, но у него есть скрытый OpenAI-совместимый API без авторизации.

**zen-gateway** — это маленький сервер, который подключается к этому бесплатному API и раздаёт его дальше как обычный OpenAI API. На телефон, на комп, куда угодно.

⚠️ **Важный момент:** zen не обязан давать тебе именно ту модель, имя которой ты запросил. За именем `deepseek-v4-flash-free` они подставляют любого провайдера из своего пула (иногда DeepSeek, иногда Claude, иногда что-то ещё). Это их «рулетка». При запуске шлюз показывает, кто выпал сейчас.

## Как это работает (принцип)

```
твой клиент (джанитор, код, чат)
   │  OpenAI-запрос (http://localhost:8787/v1)
   ▼
zen-gateway (этот скрипт)
   │  тот же запрос, один в один (Bearer public)
   ▼
opencode zen (https://opencode.ai/zen/v1)
   │  выбирает провайдера из своего пула
   ▼
DeepSeek / Claude / Nemotron / ...
```

Шлюз не переводит форматы — zen и так умеет OpenAI-формат. Скрипт просто:
1. Принимает запросы на `:8787` (с CORS, чтобы работало из браузерных клиентов).
2. Пересылает их в zen с заголовком `x-opencode-session` — этот заголовок **закрепляет провайдера**: кто выпал в первой сессии, с тем и общаешься.
3. Разбирает потоковые ответы (SSE) обратно клиенту.

Дополнительно шлюз умеет **бесконечный контекст**: когда история диалога вырастает, он сам сжимает старые сообщения в резюме (через ту же модель) и продолжает — контекст не кончается.

## Лимиты — честно и коротко

- Лимит **дневной, по IP** (сбрасывается в полночь UTC).
- У «новых» IP (младше 7 дней) — норма в два раза больше.
- Потратил норму → ошибка `429`. Лечится сменой сети/VPN (новый IP = новая норма).
- Некоторые модели доступны **не из всех регионов** — если `403`, поменяй VPN-регион.

## Установка

### Termux (Android)

```bash
pkg update -y
pkg install python git -y
git clone https://github.com/Fiopou/zen-gateway
cd zen-gateway
python zen.py serve --port 8787
```

Держи терминал открытым (или `tmux`), иначе шлюз умрёт.

### Windows

```bash
git clone https://github.com/Fiopou/zen-gateway
cd zen-gateway
python zen.py serve --port 8787
```

### Любой OpenAI-совместимый клиент

```
base_url: http://localhost:8787/v1
api_key:  любая строка (например zen)
model:    deepseek-v4-flash-free
```

Если клиент на другом устройстве — вместо `localhost` IP машины со шлюзом (Termux: `ip addr show wlan0`).

## Модели

Бесплатные (проверены вживую):

| модель | что за зверь |
|---|---|
| `deepseek-v4-flash-free` | рабочая лошадка (за именем обычно реальный DeepSeek-V3) |
| `big-pickle` | stealth-модель, сильная для рассуждений |
| `hy3-free` | Tencent Hy3 (reasoning) |
| `nemotron-3-ultra-free` | Nemotron 550B (не из всех регионов) |
| `nemotron-3.5-lightning-free` | Nemotron Lightning |
| `laguna-s-2.1-free` | — |
| `mimo-v2.5-free` | MiMo-V2.5 |

Полный список: `python zen.py models`. Увидеть, кто выпал: запуск сам пишет `[probe] модель ... -> бэкенд: ...`.

## Команды

| команда | что делает |
|---|---|
| `python zen.py serve --port 8787` | запустить шлюз |
| `python zen.py chat` | чат прямо в терминале (с авто-компактом) |
| `python zen.py "промпт"` | разовый запрос |
| `python zen.py models` | список моделей |
| `python zen.py chat "промпт" --stream` | стрим, мысли в stderr |

## Настройки окружения

| переменная | зачем |
|---|---|
| `ZEN_PORT` | порт шлюза (по умолч. 8787) |
| `ZEN_TOKEN` | пароль шлюза (Bearer) |
| `ZEN_MAX_CONTEXT` | порог сжатия истории, символов (по умолч. 150000) |
| `ZEN_PROXIES` | список прокси через запятую — случайный на каждый запрос (смена IP автоматически) |
| `ZEN_PROBE=0` | отключить пробный запрос при старте |
| `ZEN_PROBE_MODEL` | модель для пробы (по умолч. deepseek-v4-flash-free) |
| `ZEN_TIMEOUT` | таймаут запросов, сек (по умолч. 120) |

## Частые проблемы

| проблема | решение |
|---|---|
| `429 Rate limit exceeded` | дневной IP-лимит: смени сеть/VPN, подожди полночь, или дай `ZEN_PROXIES` |
| `403 Forbidden` | модель не раздаётся в твоём регионе: поменяй VPN-регион |
| `Failed to fetch` из браузерного клиента | CORS включён — проверь, что URL без `/chat/completions` на конце (клиент добавляет сам) |
| чат отвечает другой моделью | это норма: zen-рулетка. Кто выпал — закреплён за сессией; перезапусти шлюз, чтобы «перебросить кости» |

## Безопасность

- Скрипт не содержит ключей и не требует денег: zen отдаёт свободно, запрос анонимный (`Bearer public`).
- Free-модели могут использовать твои разговоры для обучения — не шли личное и секреты.
- Шлюз по умолчанию открыт для всей сети; если нужно — задай `ZEN_TOKEN`.
